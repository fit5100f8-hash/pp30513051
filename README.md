鋁圈客製化
17～20 吋鋁圈選配頁：選尺寸、J 值（7J～12J）、PCD、中心孔 CB、ET 值（0～50）、款式（三爪～十爪、雙五輻、Y 型輻、網狀、多輻）、鍛造工法（單片／雙片／三片）、顏色與表面處理，即時預覽並產生規格碼。
網頁：index.html（純 HTML/CSS/JavaScript，不連資料庫）
PWA：可安裝到手機或電腦主畫面，離線也能使用（manifest.webmanifest、sw.js、icons/）。修改 index.html 或圖示後，請把 sw.js 的 VERSION 加 1，使用者才會拿到新版。
發佈網址（GitHub Pages）：https://fit5100f8-hash.github.io/wheel-configurator/
本機預覽：在儲存庫根目錄執行 `python3 -m http.server 8000`，再開啟 http://localhost:8000/
